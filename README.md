# Solar Ventilation Regression Model

Nonlinear regression-based performance modelling of an experimentally tested solar-assisted ventilation system using Python and thermo-aerodynamic parameters.

## Project Overview

This repository presents a simplified nonlinear regression workflow developed to analyse and predict the performance of an experimentally tested solar-assisted ventilation system.

The model is based on experimentally controlled thermo-aerodynamic parameters and is intended to explore the nonlinear relationships between environmental forcing and ventilation performance.

## Research Context

The underlying experimental study investigated the combined effects of:

- Thermal buoyancy
- Wind velocity
- Collector temperature
- Inlet configuration
- Ventilation performance

Experimental measurements were obtained under controlled laboratory conditions.

## Methodology

The analysis workflow includes:

- Experimental data preprocessing
- Exploratory data analysis
- Nonlinear regression modelling
- Model fitting and performance evaluation
- Comparison between measured and predicted values
- Visualization of regression results

## Tools

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib

## Research Applications

This type of regression modelling can support:

- Performance prediction of passive ventilation systems
- Sensitivity analysis of thermo-aerodynamic variables
- Energy-efficient building design
- Building performance optimisation
- Data-driven decision support for ventilation systems
